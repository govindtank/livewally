# LiveWally - Google Play Store Listing Assets

Place your store listing assets in this folder:

## Required Assets

### App Icon
- **File**: `icon.png`
- **Size**: 512x512 px
- **Format**: PNG or JPG
- **Design**: Your app logo on a solid background

### Feature Graphic
- **File**: `feature_graphic.png`
- **Size**: 1024x500 px
- **Format**: PNG or JPG
- **Design**: Promotional banner showcasing the app

### Screenshots
- **Folder**: `screenshots/` (already in repo with app screenshots)
- **Count**: Minimum 2, maximum 8
- **Size**: Min 320px, max 3840px on any edge
- **Format**: PNG or JPG
- **Aspect ratio**: 16:9 or 9:16 recommended
- **Content**: Show key app features

### Phone Screenshots
- `phone_screenshot_1.png`
- `phone_screenshot_2.png`
- `phone_screenshot_3.png`
- etc.

### Tablet Screenshots (optional)
- `tablet_screenshot_1.png`
- `tablet_screenshot_2.png`
- etc.

## Optional Assets

### Promo Video
- YouTube URL showing app features
- Duration: 30 seconds to 3 minutes

### TV Screenshots (if applicable)
- `tv_screenshot_1.png`
- `tv_screenshot_2.png`
- etc.

## Asset Guidelines

- **No text overlays** in screenshots unless it's part of the app UI
- **No promotional text** in screenshots
- **Show real app UI**, not mockups
- **Use device frames** to make screenshots look professional
- **Consistent branding** across all assets

## Tools for Creating Assets

- **Screenshots**: Use Android Studio's built-in screen capture tool
- **Mockups**: Use tools like [MockUPhone](https://mockuphone.com/) or [Device Art Generator](https://developer.android.com/distribute/marketing-tools/device-art-generator)
- **Design**: Use Figma, Canva, or Adobe XD for feature graphics
